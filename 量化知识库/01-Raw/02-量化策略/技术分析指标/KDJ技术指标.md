这个问题问到根子上了！知道它们怎么算出来的，你就能真正理解为什么K线看“战况”、KDJ看“体温”，而不是死记硬背那些口诀。


---

### 第一部分：K线的计算（非常简单）

K线不涉及复杂公式，就是**四个价格的直观记录**：

- **阳线（涨）**：收盘价 > 开盘价
- **阴线（跌）**：收盘价 < 开盘价
- **上影线** = 最高价 - 最高价（收盘价或开盘价中较高的那个）
- **下影线** = 最低价（收盘价或开盘价中较低的那个） - 最低价

> **核心逻辑**：K线是“原始数据”，不加工，直接告诉你这一天多空双方肉搏的结果。

---

### 第二部分：KDJ的计算（关键！）

KDJ不是直接看价格，而是看**“当前收盘价在最近一段时间价格区间里的相对位置”**。这句话是灵魂，请默念三遍。

计算分三步走，从RSV到K、D、J：

---

#### 第一步：算出RSV（未成熟随机值）—— 这是“原材料”

![[Pasted image 20260718121914.png]]

- **N** 通常取 **9天**（这是系统默认）。
- **通俗理解**：把过去9天的价格范围看成一条100米的跑道，0米是最低点，100米是最高点。RSV就是告诉你**今天收盘价“跑”到了这条跑道的哪个位置**。

> **举例**：最近9天，最高价10元，最低价8元，今天收盘9.5元。  
> RSV = (9.5 - 8) / (10 - 8) × 100 = **75**。  
> 意思就是：今天收盘价已经跑到了过去9天价格区间的75%的位置，偏高了。

---

#### 第二步：算出K值和D值（这是“平滑加工”）

K和D是对RSV做的**移动平均**，让数据更平滑，不至于上蹿下跳。

- **今日K值** = 2/3 × 昨日K值 + 1/3 × 今日RSV
- **今日D值** = 2/3 × 昨日D值 + 1/3 × 今日K值

（首次计算时，昨日K和D默认用50代替）

- **通俗理解**：
  - **K线**是“快线”，给今天的RSV权重更大（1/3），反应快。
  - **D线**是“慢线”，给今天的K值权重更小（1/3），相当于K线的“平均值再平均”，所以更平滑、更滞后。

> **这就是为什么金叉死叉看K和D**：因为K跑得快，D跑得慢。当K从下往上穿D，说明短期价格位置（RSV）从低位快速回升，趋势可能反转。

---

#### 第三步：算出J值（这是“放大镜”）

![[Pasted image 20260718123004.png]]
- **通俗理解**：J值就是**K和D之间的“差距放大器”**。
  - 当K > D时，J会被拉得更高（超过100），告诉你“涨过头了”。
  - 当K < D时，J会被砸得更低（低于0），告诉你“跌过头了”。

> **这就是为什么J线最敏感**：它纯粹是K和D的差值乘以3，等于把微小的变化放大给你看，用来捕捉极端情绪。

---

### 来，我们把它们串起来看

1. **先算RSV**：用今天收盘价和过去9天的高低点比，得到一个“位置分”（0~100）。
2. **再算K和D**：对RSV做两次平滑平均，K快、D慢。
3. **最后算J**：放大K和D的差值，抓极端。

**所以整个KDJ的逻辑链就是**：

> 收盘价 → 算出RSV（位置） → 算出K（快线） → 算出D（慢线） → 算出J（极端预警）

---

### 一个帮你记忆的“生活比喻”

想象你在测**水温**：

- **RSV**：是温度计直接测出来的实时水温。
- **K值**：是你感觉到的温度（反应快，但有点波动）。
- **D值**：是你把过去3天的体感温度平均一下（更稳，不骗人）。
- **J值**：是你摸到水觉得“哇好烫”或“哇好冰”的夸张反应（提醒你极端了）。

---

### 先看默认参数（9,3,3）的“性格”

- **（9,3,3）** 中的 **9** 是计算RSV的周期，**3** 和 **3** 是K和D的平滑天数。
- 默认参数适合**日线级别的短线操作**，敏感度和稳定性比较均衡，是绝大多数软件和股民的首选。

---

### 如果把参数改短（比如改成 5,3,3）

**效果**：指标变得更“敏感”，上蹿下跳更频繁。

| 变化 | 具体影响 |
| :--- | :--- |
| **金叉死叉增多** | 信号会非常密集，可能今天金叉买入，过两天就死叉卖出。 |
| **超买超卖更早出现** | 股价稍微一涨，KDJ就冲到80以上；稍微一跌，就掉到20以下。 |
| **优点** | 适合**震荡行情**做高抛低吸，能捕捉到很小的波动利润。 |
| **缺点** | 在单边上涨或下跌行情中，会频繁发出错误信号，容易让你“卖飞”或“抄底抄在半山腰”。 |

> **适用场景**：当你判断大盘或个股处于**横盘震荡**（比如在一个箱体里上下波动）时，可以把参数调短，快进快出。

---

### 如果把参数改长（比如改成 21,3,3 或 34,3,3）

**效果**：指标变得“迟钝”，但信号更可靠。

| 变化 | 具体影响 |
| :--- | :--- |
| **金叉死叉减少** | 信号次数大幅减少，但每次出现时，股价的趋势往往已经走得比较明确。 |
| **超买超卖更难得** | 股价涨了一大截，KDJ才慢慢爬到80；跌了一大截，才慢慢掉到20。 |
| **优点** | 适合**趋势行情**，能帮你拿住大波段，不容易被短期波动甩下车。 |
| **缺点** | 反应太慢，等KDJ给出卖出信号时，股价可能已经从高点回调了不少。 |

> **适用场景**：当你判断大盘或个股处于**明确的上升或下降趋势**时，可以把参数调长，过滤掉杂音，顺应大方向。

---

### 一个更专业的改法：只改K和D的平滑参数

除了改那个“9”，你还可以把后面的两个“3”改掉，比如改成 **（9,5,3）**：

- 这样K线会更平滑（因为K = 2/3×昨日K + 1/3×RSV 中的平滑系数变了），**金叉死叉会更少、更稳**。
- 适合不喜欢频繁操作，想做波段的人。

---

### 给你一个“万能”的参考方案

如果你不想纠结，记住这个经验：

| 你的操作周期 | 推荐KDJ参数 |
| :--- | :--- |
| **超短线（1-3天）** | 5,3,3 或 6,3,3 |
| **短线（3-10天）** | **9,3,3（默认，最通用）** |
| **中短线（10-20天）** | 14,3,3 或 21,3,3 |
| **波段（20天以上）** | 34,3,3 或 55,3,3 |

---

### 一个重要的提醒

**千万不要频繁改参数！** 改参数不是为了“优化”出过去完美的买卖点（这叫“过度优化”，是新手常犯的错误），而是为了**匹配你对当前行情的判断**。

**正确的做法是**：

1. 先看大盘和个股处于**震荡**还是**趋势**状态。
2. 震荡就用**短参数**，趋势就用**长参数**。
3. 选定一个参数后，**坚持用一段时间**，不要今天改明天改，否则指标会完全失去参考意义。
