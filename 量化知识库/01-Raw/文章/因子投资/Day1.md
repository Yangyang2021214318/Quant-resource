## CAPM公式 ##
### 1. 先看公式在说什么(经济直觉层)

E[Ri] − Rf = βi（E[RM] − Rf）
左边 E[Ri] − Rf 叫做资产 i 的"预期超额收益率"——你持有这个资产,相比把钱存银行(无风险资产),期望多赚多少。右边 E[RM] − Rf 是"市场风险溢价"——整个市场相比无风险资产期望多赚多少,这是大家持有风险资产共同要求的补偿。
公式的核心想法是:一个资产能比无风险利率多赚多少,完全取决于它和市场一起"共振"的程度,这个共振系数就是 βi。如果 βi=1,资产的超额收益和市场完全同步;βi=2,市场涨跌1%,这个资产理论上涨跌2%(放大两倍的风险暴露,也要求两倍的风险补偿);βi=0,意味着这个资产的收益和市场完全不相关,这种情况下它不该有任何超额收益,因为它根本不承担系统性风险。

### 2. β 到底是什么(统计学层)

βi = cov(Ri, RM) / var(RM)
这是一个标准的简单线性回归(OLS)斜率公式。如果你把 Ri − Rf 当作因变量 y,RM − Rf 当作自变量 x,跑一个回归:
Ri − Rf = αi + βi（RM − Rf）+ εi
那么最小二乘法估计出来的斜率,正好就是 cov(x,y)/var(x),也就是 cov(Ri,RM)/var(RM)(因为减掉常数 Rf 不改变协方差和方差)。
为什么用协方差而不是直接用资产自己的方差(也就是它自身的总风险)?这是CAPM里最关键的一个洞见:资产的总风险可以拆成两部分——
var(Ri) = βi² · var(RM) + var(εi)
第一项是"系统性风险"(跟随市场涨跌的那部分,无法通过分散投资消除,因为所有资产都共享市场这个因子);第二项 var(εi) 是"特异性风险"(只跟这个资产自己有关,比如某个公司爆出丑闻),这部分风险可以通过持有一篮子不相关的资产,靠分散化"平均掉"。CAPM认为,市场只会对你无法分散掉的风险(系统性风险)付费,你承担的特异性风险不会带来额外预期收益,因为理性投资者本可以免费消除它。这就是为什么公式里只有 β(衡量系统性风险暴露),完全没出现资产自身的总波动率。  

## 方差模型（model of the variance ）
![[Pasted image 20260618132820.png]]

证明：
推导的关键前提：公式(1.5)里有四个量,但它们的"随机性"地位不一样:

α 和 β 是不随时间变化的常数(截距向量和因子暴露矩阵在这个静态因子模型里被假设固定不变),而 λt 和 εt 才是随时间 t 变化的随机变量——这是整个推导能够进行的前提。另外题目给出了关键假设 cov(λt,εt)=0,即因子收益的波动和资产的特异性扰动互不相关。
### 第一步:对常数项 α 取协方差,直接消失
协方差运算有一个基本性质:任何常数向量的协方差(以及它和任何随机向量的协方差)都是零,因为常数没有"波动"。所以对(1.5)两边取协方差矩阵时:
Cov(Rtᵃ) = Cov(α + βλt + εt) = Cov(βλt + εt)
α 这一项直接被消掉了,这也是为什么最终的(1.6)式里完全看不到 α 的影子——α 只影响均值(预期收益),不影响风险(方差/协方差)。

### 第二步:展开 Cov(βλt + εt)
协方差具有双线性性质,对于两个随机向量 X、Y:
Cov(X+Y) = Cov(X) + Cov(Y) + Cov(X,Y) + Cov(Y,X)
代入 X=βλt,Y=εt:
Cov(βλt+εt) = Cov(βλt) + Cov(εt) + Cov(βλt,εt) + Cov(εt,βλt)

### 第三步:利用 cov(λt,εt)=0 消掉交叉项
因为 β 是常数矩阵,可以从协方差里提出来:Cov(βλt,εt) = β·Cov(λt,εt) = β·0 = 0,同理 Cov(εt,βλt) 也是零(转置关系)。所以两个交叉项都消失,只剩下:
Cov(βλt+εt) = Cov(βλt) + Cov(εt)

**第四步:对 Cov(βλt) 用"矩阵夹乘"公式

这一步是整个推导里最关键的矩阵代数技巧。标量情形下你熟悉的公式是 Var(aX)=a²Var(X);推广到向量/矩阵情形,对于常数矩阵 B 和随机向量 X:
Cov(BX) = B·Cov(X)·B'
这里的"平方"变成了"左乘B、右乘B的转置"的夹乘形式,因为 Cov(X) 现在是一个矩阵,矩阵不能简单地"平方",必须用 B(...)B' 这种二次型的写法才能保证维度匹配、保证结果仍然是对称矩阵。代入 B=β,X=λt:
Cov(βλt) = β·Cov(λt)·β' = β·Σλ·β'
(Σλ 就是 K 个因子收益率自身的 K×K 协方差矩阵)** 

### 第五步:合并,得到(1.6)
Cov(εt) 本身就定义为 Σε(N个特异性扰动项的协方差矩阵)。把第四步和这个结果代回第三步:
Σ = βΣλβ' + Σε　（1.6）  

**这个公式真正在说什么**
(1.6)把N个资产之间的总体风险结构(Σ)拆成了两部分:βΣλβ' 是由"共同暴露于同一组因子"产生的系统性协方差——如果两个资产对同一因子的暴露(β)方向相近,这一项会让它们的收益呈现正相关,这正是分散化投资时"为什么挑选低相关性资产很难"的数学根源,因为只要大家都暴露在同一个市场因子上,这部分协方差就消不掉;Σε 则是纯粹各自独立的特异性风险,理论上可以通过持有足够多资产把它分散掉。这与你之前学的"系统性风险不能分散、特异性风险可以分散"的结论,在这里以协方差矩阵的形式被严格证明了出来。  

## 协方差
### 1. 先回顾标量协方差
对两个随机变量 X、Y,协方差 cov(X,Y) 衡量它们是否"同向波动"——cov(X,Y)>0 表示X变大时Y也倾向于变大;cov(X,Y)<0 表示反向;cov(X,Y)=0 表示线性意义上互不相关。而方差 var(X) 其实是协方差的一个特例:var(X)=cov(X,X),也就是一个变量和自己的协方差。

### 2. 推广到一组变量
现在假设你不是只有2个变量,而是有N个资产的收益率,组成一个向量 R=[R1,R2,...,RN]'。这N个变量两两之间一共有多少种"关系"要描述?N个方差(自己跟自己),加上 N(N-1)/2 个两两协方差,把这些数字按规律排成一个 N×N 的矩阵,就是协方差矩阵 Σ,严格定义是:
Σ = Cov(R) = E[(R−E[R])(R−E[R])']
它的第 (i,j) 个元素就是 cov(Ri,Rj)。  

![[Pasted image 20260618134953.png|1019]]  
### 3. 几个关键性质
**对称性**:Cov(Ri,Rj)=Cov(Rj,Ri) 永远成立(协方差本身不在乎谁是X谁是Y),所以图里蓝色对角线两侧的橙色格子是镜像相等的——比如A、B的协方差(3)既出现在第一行第二列,也出现在第二行第一列,数值完全一样。
**半正定性(positive semi-definite)**:对任意常数向量 a,a'Σa 实际上等于"投资组合权重为a时,组合收益率的方差"——而方差永远不可能为负,所以协方差矩阵必须满足 a'Σa≥0,这是它最重要的数学约束。如果你用样本数据估计出来的协方差矩阵不满足这个性质(比如资产数远多于样本观测数时容易出现),说明估计出了问题,这也是为什么实务中常常需要对协方差矩阵做"收缩"(shrinkage)处理。

### 4. 回到你之前看到的Σ、Σλ、Σε
现在再看(1.6)式 Σ=βΣλβ'+Σε 就很清楚了:
Σ 是N个资产收益率的协方差矩阵(N×N,正是上图这种结构);Σλ 是K个因子收益率自己的协方差矩阵(K×K,描述因子之间是否同向波动,比如市场因子和价值因子是否相关);Σε 也是一个协方差矩阵,但因为假设特异性扰动彼此独立,它的非对角线全部是0,只剩对角线上的各自方差——这正是"对角阵"这个说法的来源,你可以理解成上面那张图里把所有橙色格子都强制清零、只留下蓝色对角线的特殊情况。  

## 维度降维
![[Pasted image 20260618140456.png|1039]]  
### 1. 为什么直接估计协方差矩阵需要 T≥N

样本协方差矩阵的计算公式是(用去均值后的收益率矩阵 R̃,是一个 T×N 矩阵,每行是一个时间点、每列是一个资产,且已经减去了各自的样本均值):

Σ̂ = (1/(T−1)) R̃'R̃

这里有一个矩阵代数的基本事实:一个 T×N 矩阵和它自己的转置相乘得到的 N×N 矩阵,其秩(rank)最多是 min(T−1, N)(减1是因为去均值这一步本身消耗了一个自由度)。也就是说,你的T期历史数据,在N维空间里最多只能张成一个 T−1 维的子空间——如果 T−1 < N,这个 N×N 矩阵的秩就小于N,意味着它是"满秩不足"(rank-deficient)的,行列式为零,根本不可逆。

直觉上理解:把每个时间点的N个资产收益率看成N维空间里的一个点,你一共只有T个点。如果点的数量比维度还少,这些点连张满整个N维空间都做不到,自然没办法估计出"在每一个方向上"的方差信息——总有些方向上,你的数据完全没有提供任何变化信息,协方差矩阵在这些方向上就是退化的零。

### 2. 现实中T≥N有多不现实

假设你要管理一个覆盖3000支股票的投资组合(N=3000)。要让协方差矩阵可逆,你至少需要3000+期的历史数据。如果用日频收益率,这意味着至少需要约12年的连续交易数据;如果用周频,要将近60年。更麻烦的是,股票市场的统计特性(波动率、相关性结构)在这么长的时间跨度里基本不可能保持稳定——用10年前的数据去估计今天的风险结构,本身就不合理。所以"T≥N"在大型资产池上几乎是个无法满足的硬约束。

### 3. 多因子模型怎么绕开这个问题

关键在于(1.6)式 Σ=βΣλβ'+Σε 把一个"N×N矩阵"的估计问题,拆成了三个独立的、规模小得多的估计任务:

β(N×K的因子暴露矩阵):虽然有N个资产,但每个资产的β_i是单独通过一条时间序列回归估计出来的(资产i的收益对K个因子做回归),这只需要 T>K 期数据就够了,跟资产总数N无关。

Σλ(K×K的因子协方差矩阵):这是真正"难"的协方差矩阵估计步骤,但维度只有K(因子数量,通常是个位数到几十,远小于N)。按照同样的秩argument,只需要 T≥K 就能让它可逆——而K通常只有5到20左右,这个门槛极易满足。

Σε(对角阵):因为假设各资产的特异性扰动互相独立,你根本不需要估计任何协方差,只需要N个独立的方差σ²εᵢ,每一个都来自对应资产那条回归的残差,同样只需要 T>K 期数据。

把这三块拼起来反推出 Σ,你绕开了"T≥N"这个硬约束,只需要满足"T≥K"这个低得多的门槛。

## 账面市值比（Book-to-Market Ratio，B/M）  
**核心公式**：账面市值比 = 公司账面价值 ÷ 公司市场价值[](https://longportapp.cn/zh-HK/learn/book-to-market-ratio-101740)
- **账面价值**：指的是公司资产负债表上的股东权益，即归属于股东的净资产[](https://longportapp.cn/zh-HK/learn/book-to-market-ratio-101740)[](https://longportapp.cn/zh-HK/learn/pb-256)。它是一个基于会计准则计算的"历史成本"数据[](https://longportapp.cn/zh-HK/learn/book-to-market-ratio-101740)。
    
- **市场价值**：即公司的市值，由股价乘以总股数计算得出，反映了市场对公司未来价值的预期[](https://longportapp.cn/zh-HK/learn/book-to-market-ratio-101740)。
通俗地说，这个比率就在问：**公司的账面净资产，相对于它的股票市场价值，到底有多大？**  
**核心意义：价值股的"标签"  
账面市值比是区分"价值股"与"成长股"最核心的指标之一。
- **高账面市值比 → 价值股**：当比值较高时，通常意味着公司的市场定价相对于其账面净资产偏低，可能被低估，是价值投资者的关注对象[](https://longportapp.cn/zh-HK/learn/book-to-market-ratio-101740)[](https://longportapp.cn/zh-CN/learn/high-minus-low--100089)。
    
- **低账面市值比 → 成长股**：当比值较低时，意味着市场给予了公司较高的估值溢价，反映了投资者对其未来增长抱有较高期望[](https://longportapp.cn/zh-HK/learn/book-to-market-ratio-101740)[](https://longportapp.cn/zh-CN/learn/high-minus-low--100089)。
这个指标也是著名金融学家尤金·法玛（Eugene Fama）和肯尼斯·法兰奇（Kenneth French）提出的**三因子模型中的核心因子（HML，即高减低因子）**[](https://longportapp.cn/zh-CN/learn/high-minus-low--100089)[](https://longbridge.com/zh-HK/learn/high-minus-low--100089)。他们发现，长期来看，高账面市值比（价值股）的投资组合表现往往优于低账面市值比（成长股）的组合，这种现象被称为"价值溢价"[](https://longportapp.cn/zh-CN/learn/high-minus-low--100089)[](https://longbridge.com/zh-HK/learn/high-minus-low--100089)
