**技术分析（Technical Analysis）**
技术分析是一种基于历史价格和成交量数据来预测未来价格走势的分析方法。其核心假设是市场参与者的心理和行为模式会重复出现，通过图表形态、价格趋势、动量指标和移动平均线等多种指标来捕捉这些模式。

以下是 Alpha 探索中常用的代表性指标：

---

**RSI（相对强弱指数，Relative Strength Index）**

衡量近期价格涨跌力度的动量指标，用于判断是否"涨过头"或"跌过头"。

$$\text{RSI} = 100 - \frac{100}{1 + RS}, \quad RS = \frac{\text{N日平均涨幅}}{\text{N日平均跌幅}}$$

通常 N=14，取值 0~100：

| RSI 区间 | 含义 |
|---------|------|
| > 70 | 超买（Overbought）——涨得太猛，可能回调 |
| < 30 | 超卖（Oversold）——跌得太狠，可能反弹 |
| 50 附近 | 多空均衡，无明确方向 |

Alpha 用法：低 RSI 股票可能即将反弹（正向 Alpha），高 RSI 股票可能即将回调（负向 Alpha）。
弱点：在强趋势行情中，RSI 会持续停留在超买/超卖区（钝化），发出大量假信号。

---

**布林带（Bollinger Bands）**

用标准差在移动平均线上下各画一条轨道，价格大部分时间在轨内运行，突破轨道则是信号。

```
中轨 = N日移动平均线（通常 N=20）
上轨 = 中轨 + K × N日标准差（通常 K=2）
下轨 = 中轨 - K × N日标准差（通常 K=2）
```

统计学直觉：K=2 时，约 95% 的价格落在上下轨之间。

| 信号 | 含义 |
|------|------|
| 价格突破上轨 | 强势上涨，但也可能随时回落 |
| 价格跌破下轨 | 超跌，可能反弹 |
| 轨道收窄（挤压） | 波动率极低，大行情前兆——方向待定 |

弱点：在单边趋势行情中，价格会持续贴着轨道走，反复假突破。

---

**MACD（Moving Average Convergence Divergence，指数平滑异同移动平均线）**

用快慢两条均线的差值和信号线交叉，捕捉趋势方向和强度变化。

**前置概念：EMA（Exponential Moving Average，指数移动平均）**

EMA 与普通均线不同——它对近期价格赋予更高权重，对旧数据做指数衰减。这也是 MACD 比普通双均线交叉更灵敏的根本原因。

$$\text{EMA}_t = \text{Price}_t \cdot k + \text{EMA}_{t-1} \cdot (1 - k), \quad k = \frac{2}{N+1}$$

其中 N 是周期参数（如 12 或 26）。k 越大，对今日价格越敏感。

---

**三个组成部分及计算公式**

```
┌─────────────────────────────────────────────────────────┐
│  DIF    = EMA(Close, 12) − EMA(Close, 26)               │
│  (Difference，差离值) —— 快慢均线差值，MACD 的核心       │
│                                                          │
│  DEA    = EMA(DIF, 9)                                    │
│  (Difference Exponential Average，信号线) —— DIF 的平滑版 │
│                                                          │
│  MACD柱 = 2 × (DIF − DEA)                                │
│  (MACD Histogram，柱状线) —— 差值的变化速度               │
└─────────────────────────────────────────────────────────┘
```

**DIF（Difference，差离值）—— 趋势的方向**

DIF 是 MACD 的核心：用短期 EMA(12) 减去长期 EMA(26)。

- 12 和 26 并非随意选择——Gerald Appel 设计 MACD 时，12 日代表约两周的交易周期（捕捉短期动能），26 日代表约一个月的交易周期（捕捉中期趋势）。
- **DIF > 0**：短期 EMA 在长期 EMA 之上 → 股价处于上升趋势，多头占优
- **DIF < 0**：短期 EMA 跌破长期 EMA → 股价处于下降趋势，空头占优
- **DIF 的绝对值**反映两条 EMA 的"分离程度"——越大，趋势越强

**DEA（Difference Exponential Average，信号线）—— 趋势的确认**

$$\text{DEA}_t = \text{DIF}_t \cdot \frac{2}{10} + \text{DEA}_{t-1} \cdot \left(1 - \frac{2}{10}\right)$$

DEA 是 DIF 的 EMA(9)，即对 DIF 再做一次指数平滑。逻辑链：

1. DIF 本身波动较大，直接用它做买卖判断会产生大量噪声信号
2. 用 9 日 EMA 再平滑一次 → DEA 更平缓，过滤掉短期波动
3. 9 天恰好处于 12 和 26 之间，既不过快（避免假信号）也不过慢（避免滞后太多）

**MACD 柱（MACD Histogram，柱状线）—— 趋势的加速度**

$$\text{Histogram} = 2 \times (\text{DIF} - \text{DEA})$$

乘以 2 是为了放大视觉差异。MACD 柱的核心信息不在绝对值，而在**变化方向**：

- **柱线由负转正（翻红）**：DIF 刚刚穿过 DEA 向上 → 多头力量**正在增强**
- **柱线由正转负（翻绿）**：DIF 刚刚跌破 DEA → 空头力量**正在积聚**
- **柱线缩短**：DIF 和 DEA 正在靠拢 → **当前趋势的动能衰竭**——最被低估的预警信号

**关键要点提炼：**

| 先看什么 | 后看什么 | 为什么 |
|----------|---------|--------|
| DIF 正负 | → 决定做多还是做空 | 趋势方向是根本 |
| 柱线缩短 | → 比金叉/死叉早 3~5 天 | 动能先于方向转向 |
| 金叉/死叉 | → 确认入场时机 | 等 DIF 和 DEA 交叉确认再行动 |
| 零轴 | → 判断多空分水岭 | DIF 在零轴上方回踩不破 = 强多头 |

**Alpha 构建中的用法：**

- **DIF > 0 且柱线加长** → 正向 Alpha（趋势强劲的股票）
- **柱线缩短但价格创新高（顶背离）** → 负向 Alpha（即将反转）
- **DIF < 0 且柱线缩短（空头衰竭）** → 潜在正向 Alpha（超跌反弹）

**CLV（Close Location Value，收盘位置价值）**

CLV 用来衡量收盘价在当日价格区间内的相对位置，反映临收盘时市场的买卖力量对比。

**计算公式**

$$\text{CLV} = \frac{(\text{Close} - \text{Low}) - (\text{High} - \text{Close})}{\text{High} - \text{Low}}$$

可简化为：

$$\text{CLV} = \frac{2 \times \text{Close} - \text{High} - \text{Low}}{\text{High} - \text{Low}}$$

CLV 取值区间 **[-1, +1]**：

| CLV 值 | 含义 | 市场心理 |
|--------|------|---------|
| 接近 **+1** | 收盘价 ≈ 最高价 | 买方全天掌控，收盘时仍有买盘推高 |
| 接近 **0** | 收盘价 ≈ (高+低)/2 | 多空拉锯，盘中波动被完全抹平 |
| 接近 **−1** | 收盘价 ≈ 最低价 | 卖方全天压制，收盘时仍有卖盘砸低 |

**与 VWAP/Close 比较的区别**

CLV 和 [[量化知识库/01-Raw/Worldquant brain/Day1|Day1 中 Close vs VWAP]] 都用于解读收盘时刻的市场心理，但角度不同：

| | CLV | Close vs VWAP |
|------|-----|------|
| 比较对象 | 当日最高价 vs 最低价 | 收盘价 vs 成交量加权均价 |
| 核心问题 | 收盘在当日区间什么位置？ | 收盘价相对当日平均成本是高是低？ |
| 极端信号 | CLV = −1（收在最低） | Close ≪ VWAP（收在成本之下） |

两者可以互补：一只股票 CLV 接近 −1 且 Close < VWAP，说明不仅收在全天最低，还跌破了当日平均成本——双重看跌确认。

**Alpha 思路：均值回归（Reversion）**

CLV 是日内（短期）指标，天然更适合做**反转 Alpha**（Reversion），而非趋势跟踪（Momentum）。逻辑如下：

```
一天之内：
  买方不断推高 → 收盘在高位 → CLV ≈ +1 → 短期涨过头 → 次日可能回落 → 卖出
  卖方不断砸低 → 收盘在低位 → CLV ≈ −1 → 短期跌过头 → 次日可能反弹 → 买入
```

这与 Day1 技术分析的基础假设一致——极端的价格运动往往伴随短期反转压力。CLV 把这种"日内极端程度"量化为一个 −1 到 +1 的标准化数值，可以直接作为 Alpha 输入。

**实战用法**

| CLV 信号 | Alpha 动作 | 逻辑 |
|----------|-----------|------|
| CLV 极高（> +0.8） | 做空 / 负向 Alpha | 日内涨过头，短期均值回归向下 |
| CLV 极低（< −0.8） | 做多 / 正向 Alpha | 日内跌过头，短期均值回归向上 |
| CLV 中性 | 不操作 | 多空平衡，无明确方向性信号 |

**结合其他指标增强信号**

单独用 CLV 做反转 Alpha 容易在强趋势行情中踩坑——比如一只股票连续多日 CLV=+1，说明它确实强，不是"涨过头"。因此实战中建议组合：

- **CLV + MACD 柱缩短**：CLV 极端 + 柱线衰竭 = 反转信号更可靠
- **CLV + 成交量放大**：极端 CLV 伴随巨量 = 可能是"放量见顶/见底"
- **CLV + 布林带触轨**：CLV=−1 且价格跌破下轨 = 超跌共振，反弹概率更高

**Alpha 公式实战：`−zscore(clv) × rank(volume)`**

这个公式是 Day1（算子）和 Day2（信号逻辑）的缝合应用，本质上是一个**成交量加权的日内均值回归 Alpha**。

**逐层拆解**

```
−zscore(clv) × rank(volume)
  └──┬──┘     └────┬────┘
  反转信号         置信度权重
```

**第一层：`zscore(clv)` —— 找到 CLV 有多极端**

z-score 将当天所有股票的 CLV 做截面标准化：

$$\text{zscore} = \frac{\text{CLV} - \mu_{\text{截面}}}{\sigma_{\text{截面}}}$$

为什么不用原始 CLV？每只股票的 CLV 分布不同——有的常年偏高，有的常年偏低。z-score 消除了这种系统性偏差，只保留"相对于今天全市场，这只股票收得有多极端"这个信息：

| CLV 原始值 | 当时市场环境 | z-score | 解读 |
|-----------|-------------|---------|------|
| +0.9 | 大盘普涨，多数股票 CLV > 0.7 | +0.3 | 大家都高，你并不突出 |
| +0.5 | 大盘普跌，多数股票 CLV < −0.5 | +2.1 | 别人都跌你却收在高位，非常极端 |

**第二层：负号 `−` —— 反转方向**

`−zscore(clv)` 翻转信号，落地 CLV 的均值回归逻辑：

```
zscore(clv) = +2  →  −zscore = −2  →  日内涨过头 → 做空
zscore(clv) = −2  →  −zscore = +2  →  日内跌过头 → 做多
```

**第三层：`rank(volume)` —— 成交量加权的置信度**

`rank()` 把当日所有股票的成交量映射到 0~1 区间（来自 [[量化知识库/01-Raw/Worldquant brain/Day1|Day1 变换算子]]）：

- 成交量排名最高 → rank ≈ 1 → 信号放大到几乎是原始值
- 成交量排名最低 → rank ≈ 0 → 信号被大幅压缩

背后的逻辑：**放量的价格极端比缩量的价格极端更可信**——高价/低价是真实成交量打出来的，不是几笔零散交易画出来的。

**数值直觉**

| 场景 | zscore(CLV) | volume rank | 最终 Alpha | 解读 |
|------|------------|-------------|-----------|------|
| 热门股、日内砸过头 | −2.0 | 0.95 | **+1.90** | 强做多，高置信 |
| 冷门股、日内砸过头 | −2.0 | 0.05 | **+0.10** | 弱做多，存疑 |
| 热门股、日内涨过头 | +2.0 | 0.95 | **−1.90** | 强做空，高置信 |
| CLV 中性 | 0 | 任意 | **0** | 不操作 |

**一句话总结**

> 在成交量大的股票里，对日内涨过头的做空、对日内跌过头的做多——成交量越大，下注越重；成交量越小，信号越轻。这是一个典型的**反转型（Reversion）Alpha**，利用的是日内极端情绪在次日均值回归的规律。

**用到的 Day1 知识点**

| 概念 | 来源 | 此处作用 |
|------|------|---------|
| `rank()` | [[Day1#变换算子|Day1 变换算子]] | 将量比映射到 0~1，消除量纲，提取相对排名 |
| `zscore()` | [[Day1#变换算子|Day1 变换算子]] | 截面标准化 CLV，消除不同股票间的分布差异 |
| `volume` | [[Day1#以成交量作为指标|Day1 成交量]] | 作为置信度权重，放量信号更可信 |
| Reversion | [[Day2#Alpha 思路|Day2 CLV Alpha]] | CLV 天然适合反转策略的方向逻辑 |

**三者对比总结**

| 维度 | RSI | 布林带 | MACD |
|------|-----|--------|------|
| 类型 | 动量指标 | 波动率/通道指标 | 趋势指标 |
| 核心问题 | 涨跌有多猛？ | 价格在什么位置？ | 趋势往哪走？ |
| 核心信号 | 超买 >70 / 超卖 <30 | 触轨 = 异常、收窄 = 酝酿 | 金叉/死叉、背离 |
| 弱点 | 强趋势中持续钝化 | 趋势行情反复假突破 | 震荡市频繁假信号 |
| 适合场景 | 震荡市反转 | 识别极端行情 | 确认趋势方向 |

核心结论：这三种指标从不同维度刻画市场——RSI 看力度、布林带看位置、MACD 看方向。在 Alpha 构建中，它们各自提供了不同的选股信号来源，但单独使用任何一个都不可靠，实战中往往需要组合使用（如 MACD 定方向 + RSI 定时点），或与基本面信号混合形成多因子 Alpha。

**动量效应（Momentum Effect）**

动量效应是金融市场中最经典的现象之一：**近期涨的资产倾向于继续涨，近期跌的资产倾向于继续跌**。大量学术研究已验证这一效应存在于全球各类资产中，与前一节讨论的 CLV 均值回归形成鲜明对比——两个效应在**不同时间维度**上分别主导。

**分时间维度的表现**

| 时间周期 | 主导效应 | 说明 |
|----------|---------|------|
| 短期（< 1 个月） | **反转效应（Reversion）** | 涨多了要回调，跌多了要反弹——CLV 适用的领域 |
| 中期（3~12 个月） | **动量效应（Momentum）** | 趋势最强、最稳定——经典动量的黄金窗口 |
| 长期（> 12 个月） | 效应**逐渐衰减** | 超过一年后，动量不再显著甚至反转 |

这解释了为什么 Brains 平台中动量 Alpha 默认参数常用 250 天（约一年交易日）——卡在中期到长期的临界点，刚好在动量效应衰减前捕捉到它。

**基础实现及其问题**

最直接的动量实现是计算过去一年的价格涨幅：

```
ts_delta(close, 250) / ts_delay(close, 250)
```

- `ts_delta(close, 250)`：250 天前的价格与今天的差值
- `ts_delay(close, 250)`：250 天前的价格（作为分母）
- 两者相除 = 过去一年的百分比收益率

但**直接用这个公式做 Alpha 效果很差**。原因在于：一年的收益率中，最近几天的涨跌贡献了不成比例的影响。如果一只股票昨天大涨 5%，一年收益率看起来很强，但这更像是一个短期反转信号（昨天涨猛了今天可能回调），而非真正的动量信号。**短期反转污染了中期动量**。

**改进方案一：延迟一年收益率**

```
ts_delay(ts_delta(close, 250) / ts_delay(close, 250), 10)
```

将收益率计算出来后，再**跳过最近 10 天**（`ts_delay(..., 10)`）。

核心思路：把最近 10 天的影响从动量信号里**剥离**出去。

```
原始一年收益率 = 最近10天涨幅 + 前240天涨幅
                    ↑                 ↑
               反转效应主导         动量效应主导
               
延迟10天后     = 前240天涨幅（去掉了短期的噪声）
                   ↑
              更纯净的动量信号
```

**改进方案二：统计上涨天数**

```
ts_sum(returns > 0 ? 1 : 0, 250)
```

不关心涨了多少，只关心**涨了多久**——统计过去 250 个交易日中有多少天收益率为正。

这与收益率百分比是**互补维度**：

| 维度 | 方案（收益率） | 方案二（上涨天数） |
|------|-------------|------------------|
| 衡量什么 | 涨了多少 | 涨了多久 |
| 极端信号风险 | 一只股票单日暴涨 50% 会主导信号 | 单日暴跌不影响，只计数 |
| 选股偏好 | 偏好爆炸性涨幅的股票 | 偏好稳定持续上涨的股票 |

上涨天数多的股票，往往不是短期爆拉的类型，而是那种"每天涨一点点"的慢牛——这类股票的动量更稳健，更少受到短期反转的污染。

**三元表达式语法**

`<条件> ? <真值> : <假值>` 是 Brains 的条件语法，等价于 `if_else(条件, 真值, 假值)`：

```
returns > 0 ? 1 : 0    →  当天涨了 → 计 1，当天跌了 → 计 0
ts_sum(..., 250)       →  对 250 天求和 = 累计上涨天数
```

**两种方案对比总结**

| | 延迟收益率 | 统计上涨天数 |
|------|----------|------------|
| 公式 | `ts_delay(收益率, 10)` | `ts_sum(returns>0?1:0, 250)` |
| 思路 | 砍掉最近 10 天的反转污染 | 用"持久度"代替"涨幅" |
| 适合场景 | 想保留价格涨跌幅信息 | 想要更稳健、更少极端值的信号 |
| 与反转关系 | 通过延迟硬隔离 | 通过统计方式自然免疫短期噪声 |

**核心洞察**

动量效应和反转效应（如 CLV）并不是矛盾的——它们存在于**不同的时间频率**上：

```
短期（日级别）→ 反转主导 → CLV 类 Alpha 有效
中期（月级别）→ 动量主导 → 延迟收益率 / 上涨天数 Alpha 有效
```

一个完整的量化策略体系，往往同时包含这两个频率的信号，形成多周期 Alpha 组合。关键不在于选边站，而在于**在正确的时间尺度上用正确的效应**。


**组合构建：从 Alpha 值到持仓权重**

Brain 平台的组合构建本质上是一套**固定的标准化流水线**，用户写的 Alpha 表达式只负责产生"原始信号值"，平台自动完成后续的权重转换。整个过程分三步：

---
#### 第一步：截面排名（rank）

每个交易日，把当天全市场所有股票的 Alpha 原始值按从小到大排名，映射到 `[0, 1]` 区间：

```
rank = (该股在当日的排名次序) / (当日股票总数)
```

对你的表达式来说，"过去一年上涨天数最多"的股票得到接近 1 的排名，"上涨天数最少"的股票得到接近 0 的排名。这一步消除了量纲和分布问题。

---
#### 第二步：去均值，构造多空信号

将排名值减去截面均值 0.5，得到中心化的信号：

```
signal = rank - 0.5
```

结果自然分成两半：

- 排名靠前（rank > 0.5）→ signal 为正 → 做多候选
- 排名靠后（rank < 0.5）→ signal 为负 → 做空候选

---
#### 第三步：权重归一化（scale）

将 signal 除以所有绝对值之和，使得：

```
∑ |weight_i| = 1
```

最终每只股票得到一个持仓权重，总多头仓位 ≈ 总空头仓位，整个组合对市场整体涨跌**敞口为零**。

---

**条件逻辑：给 Alpha 装上开关**

Alpha 表达式本身每天每只股票都会产出一个值，但现实中很多信号只在特定环境下可靠。条件逻辑的作用就是**限定 Alpha 在什么时候生效**。

**基础条件**

支持常见逻辑运算符（`>`, `<`, `>=`, `<=`, `==` 等）：

```
volume > adv20              成交量超过 20 日均量
close >= ts_max(high, 50)   收盘价创 50 日新高
returns < -0.05             单日跌幅超过 5%
```

这些条件返回布尔值（true / false），本身不产生 Alpha，而是用来**控制** Alpha 的开关。

> ⚠️ 过度限制条件会大幅减少有效数据点，增加过拟合风险——条件越多，回测越好看，实盘越惨。

---

**`if_else(条件, 真值, 假值)` —— 条件分支**

两种写法等价：

```
if_else(volume > adv20, alpha_value, 0)
volume > adv20 ? alpha_value : 0
```

| 场景 | 写法 | 语义 |
|------|------|------|
| 条件不满足时空仓 | `if_else(cond, alpha, 0)` | 不放量就不持仓 |
| 条件不满足时反转 | `if_else(cond, alpha, -alpha)` | 不放量时反向操作 |
| 嵌套多条件 | `if_else(cond1, a1, if_else(cond2, a2, 0))` | 多层优先级 |

**if_else 的痛点**：它每天重新计算，没有记忆——今天放量就持仓，明天缩量立刻清零。无法"持有"仓位，不适合中长期策略。

---

**`trade_when(entry, Alpha, exit)` —— 条件开仓 + 持仓维持**

这是 Brain 平台解决"持有"问题的算子，本质是一个**带记忆的状态机**：

```
trade_when(entry_condition, Alpha_expression, exit_condition)
            └── 开仓 ──┘   └── Alpha ──┘   └── 平仓 ──┘
```

| entry | exit | 行为 |
|-------|------|------|
| **true** | false | 用当天 Alpha 值**更新**仓位 |
| false | false | **维持**上次 entry=true 时的仓位不动 |
| 任意 | **true** | **清仓**（返回 NaN） |
| 任意 | **−1** | **永不清仓**——持有到最后 |

**与 if_else 的本质区别**：

```
if_else(放量, Alpha, 0)
  → 今天放量持仓，明天缩量立刻清零 → 持仓最多 1 天

trade_when(放量, Alpha, -1)
  → 放量的那一天开仓，之后即使缩量也一直持有 → 持仓可延续数周
```

if_else 是瞬时开关，trade_when 是有记忆的状态机。

---

**实战：trade_when 应用于动量 Alpha**

原始动量信号统计过去一年上涨天数：

```
positive_days = ts_sum(returns > 0 ? 1 : 0, 250)
```

加上 trade_when 条件增强：

```
trade_when(
    volume > adv20,       ← 开仓：成交量突破 20 日均量时入场
    positive_days,        ← Alpha：过去一年上涨天数
    -1                    ← 离场：-1 表示永不清仓
)
```

**逻辑链**：放量那一天按动量信号开仓 → 之后每天持有不动 → 让中长期趋势充分展开。

为什么 exit = −1？动量效应是 3~12 个月的中长期现象，频繁进出只会增加交易成本和打断趋势累积。

**三种开仓条件对比**：

| 写法 | 含义 | 特点 |
|------|------|------|
| `volume > adv20` | 成交量超 20 日均量 | 中等敏感，捕捉温和放量 |
| `volume > ts_mean(volume, N)` | 超 N 日均量 | N 越小越敏感，可调节 |
| `volume * vwap > ts_mean(volume * vwap, N)` | 成交金额超 N 日均值 | 最稳健——统一量价维度 |

`volume * vwap`（成交金额）比纯 volume 更合理：高价股的放量和低价股的放量不可比，成交金额统一了两者。

**中性化建议**：动量效应通常跨行业发生（行业整体涨跌），因此推荐 Market 中性化而非 Industry 中性化——过于精细的分组反而会剥离你想要捕捉的跨行业动量。

---

**条件强度谱系**

```
if_else              trade_when(..., -1)        trade_when(..., exit)
    │                      │                           │
    ▼                      ▼                           ▼
 每天重判             入场后永不离场              入场后有条件离场
 最灵活 / 最碎         最坚定 / 最低成本          有始有终 / 最完整
 适合反转策略          适合中长期动量             适合有明确止盈止损的策略
```

**总结**：

| 概念 | 核心 | 一句话 |
|------|------|--------|
| 条件 | 限定信号环境 | "只在合适的时候出手" |
| `if_else` | 按条件二选一 | "条件满足用 A，否则用 B" |
| `trade_when` | 开仓 → 持有 → 平仓 | "信号来了进场，没走就不动" |
| `exit = −1` | 禁止平仓 | "买定离手，等趋势跑完" |

核心思想：好的 Alpha 不仅需要好信号，还需要好时机和好持仓管理。`trade_when` 用一个算子统一解决了"何时进、何时出、中间怎么持有"三个问题。
