# Raw 原始资料索引

`01-Raw` 用来保存原始笔记、摘录、对话记录和阅读材料。当前目录已改为按内容相关性分类，不再按“对话 / 想法 / 文章 / 日期”分类。

## 记录规则

- 新内容优先放入对应主题目录。
- 不再创建 `Day1`、`Day2` 这类时间线笔记。
- 如果暂时无法判断主题，先放入 `00-Inbox`，后续再归档。
- 原始材料可以保留上下文；提炼后的概念页应进入 `02-Wiki`。
