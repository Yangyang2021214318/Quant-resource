# 动量效应

> **一句话定义**：动量效应（Momentum Effect）是金融市场中最经典的现象之一——近期涨的资产倾向于继续涨，近期跌的资产倾向于继续跌。

---

## 分时间维度的表现

| 时间周期 | 主导效应 | 说明 |
|----------|---------|------|
| 短期（< 1 个月） | **反转效应（Reversion）** | 涨多了要回调，跌多了要反弹 |
| 中期（3~12 个月） | **动量效应（Momentum）** | 趋势最强、最稳定——经典动量的黄金窗口 |
| 长期（> 12 个月） | 效应**逐渐衰减** | 超过一年后动量不再显著甚至反转 |

这解释了为什么 Brain 平台中动量 Alpha 默认参数常用 250 天（约一年交易日）——卡在中期到长期的临界点。

---

## 基础实现及其问题

最直接的动量实现是过去一年的价格涨幅：

```
ts_delta(close, 250) / ts_delay(close, 250)
```

**问题**：一年的收益率中，最近几天的涨跌贡献了不成比例的影响。如果一只股票昨天大涨 5%，一年收益率看起来很强，但这更像短期反转信号——**短期反转污染了中期动量**。

---

## 改进方案

### 方案一：延迟一年收益率

```
ts_delay(ts_delta(close, 250) / ts_delay(close, 250), 10)
```

**核心思路**：将收益率计算出来后，跳过最近 10 天（`ts_delay(..., 10)`），把短期反转的噪声从动量信号中剥离。

```
原始一年收益率 = 最近10天涨幅 + 前240天涨幅
                    ↑                 ↑
               反转效应主导         动量效应主导

延迟10天后     = 前240天涨幅（更纯净的动量信号）
```

### 方案二：统计上涨天数

```
ts_sum(returns > 0 ? 1 : 0, 250)
```

不关心涨了多少，只关心**涨了多久**——统计过去 250 个交易日的上涨天数。

| 维度 | 方案一（收益率） | 方案二（上涨天数） |
|------|-------------|------------------|
| 衡量什么 | 涨了多少 | 涨了多久 |
| 极端信号风险 | 单日暴涨 50% 会主导信号 | 单日暴跌不影响，只计数 |
| 选股偏好 | 偏好爆炸性涨幅的股票 | 偏好稳定持续上涨的股票 |

---

## 动量 vs 反转：不同频率，不同效应

```
短期（日级别）→ 反转主导 → CLV / RSI 类 Alpha 有效
中期（月级别）→ 动量主导 → 延迟收益率 / 上涨天数 Alpha 有效
```

一个完整的量化策略体系往往同时包含这两个频率的信号，形成多周期 Alpha 组合。关键不在于选边站，而在于**在正确的时间尺度上用正确的效应**。
