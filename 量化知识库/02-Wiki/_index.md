## 因子投资体系

来源：石川、刘洋溢、连祥斌《因子投资：方法与实践》电子工业出版社，2020

| 页面 | 一句话说明 |
|-----|----------|
| [[因子投资]] | 用多因子框架系统解释资产截面收益差异的投资方法论，核心公式 E[R]=α+βλ |
| [[多因子模型]] | 将多个因子组合解释资产预期超额收益，是因子投资的核心定价工具 |
| [[异象]] | 在给定多因子模型下定价误差 α 显著不为零的资产或投资组合 |
| [[CAPM]] | 单因子资产定价模型，多因子模型的起点，被价值/规模等异象所挑战 |
| [[Fama-MacBeth回归法]] | 两步截面回归法，实证资产定价中估计因子风险溢价的标准工具 |
| [[主成分分析]] | 将多个相关变量压缩为少数互不相关主成分，用于因子降维和共线性处理 |
