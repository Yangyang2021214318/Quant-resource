# 算子体系

> **一句话定义**：算子（Operators）是 Brain 平台 Alpha 表达式的核心构件，分为向量算子、变换算子和分组算子三大类，分别负责数据聚合、分布变换和组内操作。

---

## 一、向量算子（Vector Operators）

**用途**：将多维数据（一组值 / 向量）聚合成单个代表性数值。

某些数据字段不是每只股票每天一个数值，而是一组值（如 Level 2 报价、多维财务指标、期权链数据等）。向量算子的作用就是**把这一组值聚合成一个数**。

| 算子 | 功能 | 适用场景 |
|------|------|---------|
| `vec_mean()` | 取均值 | 最常用，平滑噪声 |
| `vec_median()` | 取中位数 | 对极端值更稳健 |
| `vec_max()` | 取最大值 | 捕捉上边界信息 |
| `vec_min()` | 取最小值 | 捕捉下边界信息 |
| `vec_stddev()` | 取标准差 | 衡量内部分散程度 |

选择哪种聚合方式，本质上是判断这组数据"信息含量在哪"——在均值水平？在极端值？在分散程度？

## 二、变换算子（Transformational Operators）

**用途**：对数据矩阵（股票 × 时间）中的每个值进行数学变换，改变数值分布但不改变矩阵形状。

### 核心算子：`rank()`

将截面（当天所有股票）的原始数值映射到 `[0, 1]` 排名区间：

$$\text{rank} = \frac{\text{该股当日排名次序}}{\text{当日股票总数}}$$

**为什么 rank 是最常用的预处理**：
- 消除量纲差异（市值 vs 利润率不可直接比较）
- 消除极端值影响（排名只看顺序，不看绝对值）
- 让截面信号可比

### 其他常用变换算子

| 算子 | 功能 | 典型用途 |
|------|------|---------|
| `log()` | 对数变换 | 压缩右偏分布（如市值、成交量） |
| `zscore()` | 标准化 | $\frac{x - \mu}{\sigma}$，截面均值为 0、标准差为 1 |
| `sign()` | 取符号 | 只保留方向信号（+1 / 0 / -1） |
| `truncate()` | 截断 | 限制极端值范围 |

---

## 三、分组算子（Group Operators）

**用途**：依赖分组字段（如行业、板块、国家）在组内做操作，消除跨组系统性偏差。

| 算子 | 功能 | 应用 |
|------|------|------|
| `group_neutralize()` | 组内中性化 | 减去同组均值 → 提取组内超额信号 |
| `group_rank()` | 组内排名 | 在同行业内排名 |
| `group_zscore()` | 组内标准化 | 在同行业内做 z-score |

### group_neutralize 的重要性

最常见的应用是**行业中性化**（详见 [[中性化#行业中性化]]）：

```
group_neutralize(alpha, industry)
→ Alpha 值 - 同行业均值 → "相对于同行业"的超额信号
```

这样可以避免 Alpha 在行业轮动时失效——信号的来源是选股能力，不是行业押注。
