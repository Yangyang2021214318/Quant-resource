# 多因子模型

用多个因子同时解释资产预期超额收益截面差异的线性定价模型，是[[因子投资]]的核心工具。

## 基本形式

$$E[R_i^e] = \beta_i'\lambda = \beta_{i1}\lambda_1 + \beta_{i2}\lambda_2 + \cdots + \beta_{iK}\lambda_K$$

时序展开形式：

$$R_{it}^e = \alpha_i + \beta_i'\lambda_t + \varepsilon_{it}$$

其中：
- $K$：因子数量
- $\beta_{ik}$：资产 $i$ 对因子 $k$ 的暴露（因子载荷）
- $\lambda_k$：因子 $k$ 的预期收益（风险溢价）
- $\alpha_i$：定价误差，显著非零则为[[异象]]

## 选择因子的原则

1. **相互独立**：高度相关的因子代表同类风险，不宜同时加入
2. **简约法则（Law of Parsimony）**：每个因子代表资产的某种共性风险，因子数量有限
3. **增量贡献**：加入新因子须对解释截面差异有显著增量

学术界主流多因子模型通常包含 3～5 个因子。

## 主流模型

| 模型 | 因子 | 提出时间 |
|------|------|---------|
| [[CAPM]] | 市场因子 | 1960s |
| Fama-French 三因子 | 市场 + SMB（规模）+ HML（价值）| 1993 |
| Carhart 四因子 | FF3 + MOM（[[动量效应|动量]]）| 1997 |
| Hou-Xue-Zhang（HXZ）四因子 | 市场 + ME + IA + ROE | 2015 |
| Fama-French 五因子 | FF3 + RMW + CMA | 2015 |
| Barra CNE6（A股）| 1个国家因子 + 9个风格因子 + 行业因子（需[[中性化|行业/市值中性化]]处理）| — |

## 协方差矩阵应用

多因子模型最重要的工程价值之一是简化协方差矩阵估计：

$$\Sigma = \beta \Sigma_\lambda \beta' + \Sigma_\varepsilon$$

- $\Sigma$（N阶）：资产协方差矩阵，直接估计需要 $T \gg N$，实际中不可行
- 通过多因子模型降维为估计 $\Sigma_\lambda$（K阶，K远小于N）
- Barra模型是这一应用最著名的实践案例

## 方法论

- **[[Fama-MacBeth回归法]]**：分两步估计因子暴露与因子收益率
- **GRS检验**：检验所有资产定价误差 $\alpha_i$ 是否联合为零
- **均值—方差张成（Spanning）检验**：判断新因子是否提供独立信息
