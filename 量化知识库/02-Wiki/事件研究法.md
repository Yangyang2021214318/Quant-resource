# 事件研究法

通过计算特定事件前后的异常收益来衡量市场对该事件信息反应程度的实证方法。

## 核心思路

1. 定义"事件"（如公告、问答量异常）
2. 用估计窗口建立预期收益基准（市场模型）
3. 在事件窗口计算**异常收益（Abnormal Return, AR）**：
   $$AR_{it} = R_{it} - (\hat{\alpha}_i + \hat{\beta}_i R_{Mt})$$
4. 累计得到 **[[累计异常收益]]（CAR）**

## 关键时间窗口

| 窗口类型 | 说明 | 典型设置 |
|---------|------|---------|
| 估计窗口（Estimation Window）| 建立预期收益基准 | [-150, -30]（120交易日）|
| 事件前窗口（Pre-event）| 检测信息泄露/价格预漂移 | [-5,-1]、[-3,-1] |
| 事件窗口（Event Window）| 主要分析区间 | [0,0]、[-1,+1] |
| 事件后窗口（Post-event）| 检验持续效应或反转 | [0,+5]、[0,+20] |

## 市场模型

最常用的基准模型（OLS时序回归）：

$$R_{it} = \alpha_i + \beta_i R_{Mt} + \varepsilon_{it}$$

- 估计窗口内回归得到 $\hat{\alpha}_i$、$\hat{\beta}_i$
- 中位数 $\hat{\beta} \approx 1.07$（A股CSI 300成分股实证数据）
- 通常要求最少60个有效观测才进行检验

## 事件识别（A股投资者问答场景）

在 [[论文-A股投资者问答LLM事件研究]] 中，事件识别条件：
1. **异常尖峰**：qa_count > qa_count_ma90 + 2 × qa_count_std90（2σ阈值）
2. **绝对数量**：qa_count ≥ 5（排除低活跃股偶发尖峰）
3. **基线有效**：90日均值非空且标准差 > 0
4. **冷却期**：同一股票相邻事件须间隔 ≥ 30 交易日

## 事件清洁（Multi-Flag Architecture）

为控制内生性，对每个事件打4个独立标记：

| 标记 | 定义 | 占比 |
|-----|------|-----|
| has_announcement | [-2,+1]窗口内有公司公告 | 49% |
| is_industry_wide | 同行业 ≥ 30% 股票同期有事件 | 6.4% |
| pre_event_volatile | 事件前5日累计收益绝对值 > 5% | 35.6% |
| weak_signal | qa_count < 8 或 qa_count_z < 3 | 78.9% |

四个标记同时为 False 的"完全干净事件"共 69 个，是最严苛的稳健性子样本。

## 统计检验

- $t$ 检验：CAR 均值是否显著异于零
- 多窗口同时报告：避免数据窥探，要求方向一致性
- 稳健性：不同年份子样本、不同事件清洁条件下结论是否一致
