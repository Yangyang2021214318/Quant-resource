# 中性化

> **一句话定义**：中性化（Neutralization）是在 Alpha 建模中**剔除已知风险因子影响**的预处理技术，目的是让 Alpha 只赚"选股"的钱，不赚"赌风格/赌行业"的钱。

---

## 为什么需要中性化

原始 Alpha 信号可能包含你不想要的暴露：

- 所有科技股的 Alpha 都偏高 → 实际是在赌科技行业上涨，不是选股能力
- 大市值股票 Alpha 偏低 → 实际是在赌小盘股跑赢，不是选股能力

中性化可以剥离这些系统性偏差，让 Alpha 信号变成**相对于同类的超额信号**。

---

## 市场中性化（Market Neutralization）

**目标**：剔除市场整体涨跌（Beta）的影响。

构建**多空组合**（long-short portfolio）：等额做多 Alpha 最高的股票、等额做空 Alpha 最低的股票，多空抵消 → 市场 Beta 归零 → 只留下纯 Alpha。

> 纯多头策略无法摆脱市场涨跌的影响，而多空组合通过等额的多头和空头仓位，对冲掉市场风险（Beta），只留下选股带来的纯粹 Alpha。

---

## 行业中性化（Industry Neutralization）

**目标**：在每个行业内部独立进行多空配对，剥离行业整体涨跌的影响。

核心操作：`group_neutralize()` —— 将 Alpha 值减去同行业均值，让信号变成"相对于同行业"的超额信号。

```
原始 Alpha  →  减去同行业均值  →  行业中性 Alpha
   +3.0          行业均值 +2.5        +0.5（行业内偏强）
   +1.0          行业均值 +2.5        -1.5（行业内偏弱）
```

行业中性化后的 Alpha 只赚"行业内选股"的钱，不依赖行业轮动。

---

## 市场 vs 行业中性化：如何选

| 场景 | 推荐 | 原因 |
|------|------|------|
| 动量 Alpha（跨行业） | 市场中性化 | 动量效应跨行业发生，行业中性化会过度剥离 |
| 价值 Alpha（行业内选股） | 行业中性化 | 低估值效应在行业内部更显著 |
| 通用 Alpha | 两者结合 | 做最纯净的信号 |
