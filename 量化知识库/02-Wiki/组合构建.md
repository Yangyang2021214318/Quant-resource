# 组合构建

> **一句话定义**：组合构建是将 Alpha 信号值转换为实际持仓权重的标准化流水线，Brain 平台自动完成截面排名 → 去均值 → 权重归一化的三步流程。

---

## Brain 平台的三步流水线

### 第一步：截面排名（rank）

每个交易日，把当天全市场所有股票的 Alpha 原始值按从小到大排名，映射到 `[0, 1]` 区间：

```
rank = (该股在当日的排名次序) / (当日股票总数)
```

"过去一年上涨天数最多"的股票得到接近 1，"上涨天数最少"的得到接近 0。这一步消除量纲和分布问题。

### 第二步：去均值，构造多空信号

将排名值减去截面均值 0.5，得到中心化的信号：

```
signal = rank - 0.5
```

结果自然分成两半：
- 排名靠前（rank > 0.5）→ signal 为正 → 做多候选
- 排名靠后（rank < 0.5）→ signal 为负 → 做空候选

### 第三步：权重归一化（scale）

将 signal 除以所有绝对值之和：

```
∑ |weight_i| = 1
```

最终每只股票得到一个持仓权重，总多头仓位 ≈ 总空头仓位，整个组合对市场整体涨跌**敞口为零**。

---

## 组合构建前的预处理

在实际进入三步流水线之前，Alpha 信号通常经过以下预处理（参见 [[算子体系]] 和 [[中性化]]）：

1. 去极值 → 标准化（`zscore` / `rank`）
2. 中性化（剔除行业、市值等风险因子影响）
3. Decay（平滑信号，降低换手）

---

## 设计哲学

这套流水线的核心设计理念：

- **截面可比**：rank 确保不同股票的 Alpha 在 0~1 区间可比
- **多空平衡**：去均值后多空两端权重自动对称
- **敞口归零**：最终组合对市场 Beta 的净暴露为 0
