# Chapter 2 脑筋急转弯与逻辑题

## 解题总原则

脑筋急转弯并不只是考“灵感”，更常考以下能力：

- 把复杂叙述压缩成数学对象；
- 发现不变量；
- 把问题拆成互斥情形；
- 从反面证明不可能；
- 用最少的信息完成区分。

## 2.1 Problem simplification：问题简化

### 通用方法

先问：题目真正要求的是什么？哪些信息只是故事背景？

常用简化方式：

- 用状态表示系统，而不是描述每个动作；
- 只跟踪会影响最终答案的量；
- 将连续问题离散化；
- 先研究小规模情形，再寻找规律。

### 示例：两次选择问题

若每次选择只有成功/失败两种结果，且成功概率为 (p)，失败概率为 (1-p)，那么“第一次成功发生在第 (k) 次”的概率为：

\[
P(T=k)=(1-p)^{k-1}p
\]

这就是几何分布。其期望等待次数为：

\[
E[T]=\frac{1}{p}
\]

### Python 验证

```python
import numpy as np

rng = np.random.default_rng(7)
p = 0.2
n = 200_000

# 几何分布：第一次成功出现的试验编号
waiting_times = rng.geometric(p, size=n)
print("模拟均值:", waiting_times.mean())
print("理论均值:", 1 / p)
```

## 2.2 Logic reasoning：逻辑推理

### 事件树

遇到多步随机过程，可以把每一步的可能结果画成树。若路径代表互斥事件，则总概率等于各路径概率之和；若路径需要连续发生多个独立事件，则路径概率等于概率之积。

### 条件概率框架

\[
P(A\mid B)=\frac{P(A\cap B)}{P(B)}, \qquad P(B)>0
\]

解题时先判断题目是否改变了样本空间。看到“已知”“在……条件下”“观察到……”时，通常要重新计算条件概率，而不是直接使用原概率。

### 贝叶斯公式

\[
P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B)}
\]

其中 (P(A)) 是先验概率，(P(B\mid A)) 是似然，(P(A\mid B)) 是后验概率。

### 常见陷阱

- 把 (P(A\mid B)) 当成 (P(B\mid A))；
- 把“至少一次”算成“恰好一次”；
- 忽略基准率；
- 默认事件独立；
- 用平均值代替整个分布。

## 2.3 Thinking out of the box：换一种表示

### 核心思想

当直接枚举很困难时，改变表示方式往往更有效：

- 把物体映射到整数或二进制状态；
- 把路径问题转为图问题；
- 把称量问题转为编码问题；
- 把“保证成功”转为“排除最坏情况”。

### 面试表达

不要只说“我想到一个技巧”。应说明：

1. 原表示为什么困难；
2. 新表示保留了哪些信息；
3. 新表示如何减少状态数或试验次数；
4. 如何证明它覆盖所有情况。

## 2.4 Symmetry：对称性

### 核心思想

如果问题在交换对象、旋转、镜像或重新标号后不变，可以把对称情况归为同一类。

例如，公平硬币连续抛掷时，正反面在概率上对称；若一个问题只依赖于“出现正面的次数”，而不依赖具体顺序，就可以使用二项分布：

\[
P(X=k)=\binom{n}{k}p^k(1-p)^{n-k}
\]

公平硬币时 (p=1/2)。

## 2.5 Series summation：级数求和

### 几何级数

当 \(|r|<1\) 时：

\[
1+r+r^2+\cdots=\frac{1}{1-r}
\]

常见于重复折扣、持续等待和多阶段收益。

### 望远镜求和

若通项可以写成差分：

\[
\sum_{k=1}^{n}(a_k-a_{k+1})=a_1-a_{n+1}
\]

中间项会抵消。看到分母为相邻整数乘积时，可以尝试部分分式：

\[
\frac{1}{k(k+1)}=\frac{1}{k}-\frac{1}{k+1}
\]

## 2.6 Pigeonhole principle：抽屉原理

### 基本结论

把 (n+1) 个对象放入 (n) 个盒子，至少有一个盒子包含至少两个对象。

更一般地，把 (N) 个对象放入 (k) 个盒子，至少有一个盒子包含：

\[
\left\lceil\frac{N}{k}\right\rceil
\]

个对象。

### 解题步骤

1. 确定“对象”是什么；
2. 确定“盒子”是什么；
3. 计算盒子数量；
4. 用最坏情况下仍成立的方式证明保证性结论。

## 2.7 Modular arithmetic：模运算

### 基本性质

\[
a\equiv b\pmod m
\]

表示 (a-b) 是 (m) 的倍数。

模运算常用于：

- 星期和日历问题；
- 周期性重复；
- 大整数末位；
- 编码和哈希；
- 证明某些情况不可能出现。

### 例：9 的整除性

因为 (10\equiv1\pmod 9)，所以十进制数的各位数字之和与原数模 9 同余。因此可以用数字和判断一个数是否被 9 整除。

## 2.8 Mathematical induction：数学归纳法

### 标准结构

要证明命题 (P(n)) 对所有 (n\ge n_0) 成立：

1. 基础步：证明 (P(n_0)) 成立；
2. 归纳假设：假设 (P(k)) 成立；
3. 归纳步：证明 (P(k+1)) 成立。

### 面试中的重点

不要只写出递推式。要明确说明：基础步覆盖起点，归纳步把“任意一个已成立的规模”推进到下一个规模。

## 2.9 Proof by contradiction：反证法

### 使用场景

当目标是证明“不存在”“不可能”“至少一个”“必然成立”时，反证法通常很有效。

步骤：

1. 假设结论不成立；
2. 从该假设推出必要后果；
3. 找到与已知条件或数学事实的矛盾；
4. 得出原结论成立。
