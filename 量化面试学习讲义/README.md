# A Practical Guide to Quantitative Finance Interviews 学习讲义

本目录是基于 Xinfeng Zhou《A Practical Guide to Quantitative Finance Interviews》的中文学习笔记，不是原书全文翻译。内容采用“英文概念摘要 + 中文解释 + 公式 + 解题框架 + Python 验证”的形式，适合自学和面试复习。

## 学习顺序

1. 面试通用原则与脑筋急转弯
2. 微积分与线性代数
3. 概率论与统计
4. 随机过程
5. 金融数学与衍生品
6. 编程与综合面试

## 建议使用方法

每道题先限时独立思考，再查看解题框架；最后运行对应 Python 实验，检查直觉是否与模拟结果一致。
